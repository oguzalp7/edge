# 🤖 /edge-agentecho — Autonomous Visual Feedback Consumer & Execution Engine

> *"The Producer captures visual truth from the user's eye; the Consumer executes surgical reality into the codebase. Zero prompts, zero friction, 100% deterministic isolation."*

`edge-agentecho` is the automated execution engine that consumes visual feedback tickets generated by the `agentecho-axi` Chrome extension and ingested by `agentecho-bridge`.

---

## 🧭 Temel İnvaryantlar ve Kurallar (Core Invariants)

1. **Sıfır İstemle Tüketim (Zero-Prompt Intake):**
   - Kullanıcının chat üzerinden dosya adı, bileşen ismi veya yapılması gerekenleri tekrar anlatmasına **asla gerek yoktur**.
   - `/edge-agentecho` çağrıldığında doğrudan hedef projenin `.edge/specs/` dizinindeki ve `tasks-axi` kuyruğundaki tüm aktif `ae-*` biletlerini otomatik olarak tarar ve sırayla eritir.

2. **🐧 WSL2-First Doktrini:**
   - Tüm işlemler **istisnasız** WSL2 ortamında (`/home/oguz/...`) yürütülür.
   - Komutlar `wsl bash -c "cd /home/oguz/<project> && ..."` veya WSL kabuğu üzerinden koşturulur.

3. **🌳 Zero-Touch Primary Working Tree İnvaryantı:**
   - Ana proje çalışma ağacında (`/home/oguz/<project>`) **asla doğrudan kod düzenlenemez**.
   - Her bilet için Treehouse havuzundan izole bir worktree kiralanır:
     ```bash
     WORKTREE_PATH=$(treehouse get --lease -b feat/<slug>)
     ```
   - Tüm dosya düzenleme, JSX ameliyatı, `tsc` derleme ve test koşumu kiralanan worktree içinde (`$WORKTREE_PATH`) icra edilir.

4. **🍽️ Sabit İstasyon Yönlendirmesi (Station Roster):**
   - **`ACTION: REMOVE` $\rightarrow$ `SURGEON` İstasyonu:**
     - Hedef bileşeni ve çocuklarını (children) AST/JSX düzeyinde temizler.
     - Sadece o bileşene ait olan yetim import'ları, state'leri ve handler'ları tasfiye eder.
     - Kalan kapsayıcının (grid, flex, spacing) görsel/yapısal dengesini korur.
   - **`ACTION: MODIFY` $\rightarrow$ `CODER` İstasyonu:**
     - Şartnamede (`.edge/specs/<slug>.md`) yer alan `User Directive` ve `Acceptance Criteria` maddelerine göre kodu düzenler.
     - Projenin mevcut stil diline (Tailwind, Dark Mode vb.) %100 sadık kalır.

5. **🛡️ Deterministik Doğrulama Kapısı (Verification Gate):**
   - Worktree içinde `npx tsc --noEmit` (veya `npm run type-check`) çalıştırılır. Çıkış kodu **0** olmak zorundadır.
   - Varsa ilgili bileşen/birim testleri (`npm test` veya `npx vitest run`) koşturulur. Çıkış kodu **0** olmak zorundadır.
   - Doğrulama geçmeden ana dala birleştirme yapılamaz.

6. **⚡ Fast-Forward Birleştirme & Temizlik (Merge & Teardown):**
   - Worktree içinde commit atılır: `git commit -m "refactor(ui): [agentecho] <title> (<slug>)"`.
   - Worktree havuza iade edilir: `treehouse return "$WORKTREE_PATH"`.
   - Ana repoda fast-forward merge yapılır: `git merge --ff-only feat/<slug>`.
   - Dal temizlenir: `git branch -d feat/<slug>`.
   - Bilet kapatılır: `tasks-axi done <slug>`.
   - Tamamlanan spek arşive taşınır: `mkdir -p .edge/specs/archive && mv .edge/specs/<slug>.md .edge/specs/archive/`.

## 🔄 Otomasyon Döngüsü (Autonomous Execution Loop)

Ajan `/edge-agentecho` komutunu aldığında aşağıdaki durum makinesini kuyruktaki tüm `ae-*` biletleri bitene kadar sırayla işletir:

```
+-----------------------------------------------------------------------------+
|                          1. INTAKE & QUEUE SCAN                             |
|  - Check .edge/specs/ae-*.md and `tasks-axi list --state ready`             |
|  - Collect all pending visual feedback tickets                              |
+--------------------------------------+--------------------------------------+
                                       |
                                       v
+-----------------------------------------------------------------------------+
|                         2. LEASE TREEHOUSE WORKTREE                         |
|  - WORKTREE_PATH=$(treehouse get --lease -b feat/<slug>)                    |
|  - Read .edge/specs/<slug>.md (Target file, line, selector, directive)      |
+--------------------------------------+--------------------------------------+
                                       |
                                       v
+-----------------------------------------------------------------------------+
|                     3. STATION DISPATCH (SURGEON / CODER)                   |
|  - If REMOVE: Excise JSX element, prune orphan imports & variables          |
|  - If MODIFY: Apply requested edits adhering to acceptance criteria         |
+--------------------------------------+--------------------------------------+
                                       |
                                       v
+-----------------------------------------------------------------------------+
|                     4. DETERMINISTIC VERIFICATION GATE                      |
|  - Run: npx tsc --noEmit inside $WORKTREE_PATH                              |
|  - Run: project tests inside $WORKTREE_PATH                                 |
|  - If fail: Station fixes error immediately before proceeding               |
+--------------------------------------+--------------------------------------+
                                       |
                                       v
+-----------------------------------------------------------------------------+
|                     5. FAST-FORWARD MERGE & TEARDOWN                        |
|  - Commit in worktree: git commit -m "refactor(ui): [agentecho] ..."        |
|  - Release worktree: treehouse return "$WORKTREE_PATH"                      |
|  - In main repo: git merge --ff-only feat/<slug> && git branch -d feat/<slug>|
|  - Close ticket: tasks-axi done <slug>                                      |
|  - Archive spec: mv .edge/specs/<slug>.md .edge/specs/archive/              |
+--------------------------------------+--------------------------------------+
                                       |
                                       v
                        [Are there more pending tickets?]
                             |                      |
                            YES                     NO
                             |                      |
                             +---- Loop to 1        v
                                          +---------------------+
                                          | 6. FINAL SUMMARY    |
                                          | - Render report     |
                                          +---------------------+
```

## 💻 Standart Komut Şablonları

### Adım 1: Kuyruğu Keşfetme
```bash
# Proje dizininde bekleyen biletleri listele
cd /home/oguz/<project>
tasks-axi list | grep "ae-"
ls -la .edge/specs/ae-*.md 2>/dev/null
```

### Adım 2: Worktree Kiralama
```bash
cd /home/oguz/<project>
WORKTREE_DIR=$(treehouse get --lease -b feat/<slug>)
echo "Leased worktree at: $WORKTREE_DIR"
```

### Adım 3: Ameliyat & Doğrulama (Worktree İçinde)
```bash
cd "$WORKTREE_DIR"
# Dosyayı düzenle (replace_file_content / write_to_file)
# Tip ve linter doğrulaması
npx tsc --noEmit
# Varsa test doğrulaması
npm test -- --run 2>/dev/null || true
```

### Adım 4: Commit & İade
```bash
cd "$WORKTREE_DIR"
git add .
git commit -m "refactor(ui): [agentecho] <action> <component-name> (<slug>)"

# Worktree'yi serbest bırak
treehouse return "$WORKTREE_DIR"
```

### Adım 5: Ana Dalda Fast-Forward Merge & Bilet Kapatma
```bash
cd /home/oguz/<project>
git merge --ff-only feat/<slug>
git branch -d feat/<slug>
tasks-axi done <slug>
mkdir -p .edge/specs/archive
mv .edge/specs/<slug>.md .edge/specs/archive/
```
